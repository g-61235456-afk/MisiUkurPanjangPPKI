# Misi Unit Masa – Tahun 6 PPKI

Game Matematik mudah untuk murid PPKI (Masalah Pembelajaran), unit **Saat, Minit dan Jam**.

Ciri:
- Nota, panduan dan contoh penukaran unit masa.
- 15 soalan mudah.
- Ruang nama murid.
- Markah, peratus dan pencapaian akhir.
- Muzik latar ceria dan lebih kuat; boleh dimatikan.
- Fungsi baca teks dan teks besar.
- Berfungsi offline.

Fakta asas:
- 60 saat = 1 minit
- 60 minit = 1 jam
- 1 jam = 3,600 saat
